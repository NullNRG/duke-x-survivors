Duke X — Credits and data policy

Duke X is a fan modification based on EDuke32, Build and the EDuke32 WebAssembly fork. This website does not include any Duke Nukem 3D game data, artwork, retail maps, sounds or GRP files.

Players provide their own DUKE3D.GRP locally. It is read by JavaScript in this browser and written to the WebAssembly virtual filesystem without being sent to a server. The original shareware data, if used, is subject to 3D Realms' shareware license. Other versions require lawful acquisition.

The default rendering mode is Classic. Experimental Three.js rendering can be enabled in Settings → Display. Public-preview multiplayer is disabled.
